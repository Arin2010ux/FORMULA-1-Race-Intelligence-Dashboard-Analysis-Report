# Formula 1 Racing Data Analysis

## 📌 Project Overview
This project focuses on analyzing Formula 1 racing data using Tableau to identify performance trends, compare drivers and constructors, and explore different aspects of race strategy and reliability. Interactive visualizations help transform raw racing data into meaningful insights.

## 🎯 Objectives
- Analyze driver performance and points across races and seasons.
- Compare constructor performance over time.
- Explore tyre strategies across different circuit types.
- Examine podium achievements and race results.
- Identify common DNF (Did Not Finish) causes and reliability patterns.
- Build an interactive Tableau dashboard to communicate key findings.

## 📊 Key Visualizations
The project includes visualizations covering:

1. Constructor Points by Season
2. Tyre Strategy by Circuit Type
3. Driver Performance by Laps Led
4. Driver Points Leaderboard
5. Race Distribution by Host Country
6. Driver Podium Achievements
7. DNF Causes by Team
8. DNF Patterns by Circuit and Season
9. Non-DNF Rate by Driver and Season
